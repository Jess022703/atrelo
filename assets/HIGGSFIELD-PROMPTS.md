## 🎨 Identidad de marca (referencia)

- **Logo:** dos aros / anillos entrelazados (símbolo de conexión e infinito), con brillo neón.
- **Paleta:**
  - Fondos: `#050410` (deep), `#08071a`, `#100c2c`, `#1c1444`
  - Azul `#3f6dff` · Violeta `#7b3ff0` · Magenta `#c44ce0` · Acento cyan `#36c5ff`
  - Texto/luz: `#f6f7ff`, `#b8bee0`
  - Gradiente principal: `azul → violeta → magenta` (95°)
- **Estética:** aurora/nebulosa difuminada, glassmorphism, sparkles, neón oscuro, futurista premium, tipografía tipo Poppins.

### STYLE SUFFIX (reutilizable — pégalo al final de cualquier prompt)
```
Atrelo brand style: deep near-black background (#050410 to #100c2c), electric blue-to-violet-to-magenta neon gradient (#3f6dff, #7b3ff0, #c44ce0), soft volumetric aurora glow, subtle cyan rim light (#36c5ff), glassmorphism, delicate sparkle highlights, premium futuristic tech aesthetic, cinematic soft studio lighting, shallow depth of field, clean minimal composition, high dynamic range, crisp edges, ultra sharp focus, highly detailed, octane render, 8k, no text unless specified.
```


### 🎛️ Modificadores técnicos por categoría (opcional, para más control)
Añade el modificador de la categoría **antes** del STYLE SUFFIX cuando quieras más precisión:

- **Logos / marcas:** `centered composition, generous negative space, symmetrical, vector-clean edges, subtle bloom, isolated subject`
- **Fondos / texturas:** `full-bleed, seamless, no focal subject, evenly balanced glow, wallpaper-grade, motion-blur ribbons`
- **Hero / key visuals:** `cinematic wide shot, 35mm lens, dramatic rim lighting, deep atmospheric fog, strong focal subject, rule-of-thirds, copy space`
- **Iconos 3D:** `isometric 3D render, frosted glass material, soft studio HDRI lighting, consistent 45° angle, floating with soft contact shadow`
- **Social / promos:** `flat-lay-friendly, clear negative space for headline, high contrast focal point, thumb-stopping, marketing-grade`
- **Mockups / merch:** `product photography, 50mm lens, softbox lighting, realistic reflections and shadows, shallow depth of field, photorealistic`
- **Finance UI / dashboards:** `clean UI design, pixel-perfect, glassmorphism cards, legible data-viz, dribbble-quality, dark mode interface`
- **Tarjetas fintech:** `macro product shot, 100mm lens, brushed metal texture, embossed detail, dramatic reflections, luxury render`

> **Tip de texto:** los modelos escriben mal frases largas. Si un prompt dice `"Atrelo Finance"` o headlines, o bien acepta que puede salir deforme, o mejor deja el espacio vacío ("space for headline") y superpón el texto real en Canva/Figma.

### Notas de uso
- **Aspect ratios** sugeridos: `1:1` (posts/iconos), `4:5` (posts verticales IG), `9:16` (Reels/Stories/mobile), `16:9` (banners/hero/web).
- Para **logos limpios sin fondo**: añade `on a plain white background, isolated, no shadow` o pide versión para recortar y luego usa *remove background*.
- Para **texto legible**: los modelos de imagen escriben texto con errores; deja "espacio para copy" y agrega el texto real después en Canva/Figma en vez de pedir frases largas.
- Mantén el **STYLE SUFFIX** para que todo el batch se vea como una sola familia visual.
